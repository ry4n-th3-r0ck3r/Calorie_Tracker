# Calorie Tracker

A simple Android calorie and fitness tracking application built with Kotlin and Jetpack Compose.

## About

Calorie Tracker is a lightweight, local first application for tracking daily calorie intake and fitness activity.

The project is being built from scratch as both a practical Android application and a way to develop experience with Kotlin and Android development.

## Goals

The application is intended to provide:

* Daily calorie goal tracking
* Calorie intake tracking
* Exercise and calorie expenditure tracking
* Remaining calorie calculations
* Progress visualization
* Locally stored food and exercise data
* Historical tracking and graphs

## Privacy

Calorie Tracker is designed to operate locally on the user's device.

The project is intended to require:

* No user account
* No advertising
* No analytics or telemetry
* No location access
* No unnecessary device permissions
* No Internet connection for normal operation

User data will remain on the device unless the user explicitly chooses to export it.

## Current Status

Early development.

Currently implemented:

* Basic Android application
* Jetpack Compose interface
* Editable daily calorie goal
* Numeric calorie input

## Technology

* Kotlin
* Android
* Jetpack Compose
